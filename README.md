### 🛡️ Key Features / المميزات الأساسية

* **Stealth Engine (وضع التخفي):** Uses custom **SYN Stealth** to minimize exposure to IDS/IPS and Wireshark detection. / يعتمد على تقنية SYN-Scan المخصصة ليعمل بعيداً عن أعين برامج المراقبة.
* **Blazing Performance (سرعة فائقة):** Leverages powerful **Multi-threaded execution** to audit hundreds of ports in seconds. / يعتمد على المعالجة المتعددة لفحص مئات البورتات في ثوانٍ.
* **Intelligent Discovery (كشف ذكي):** Automatically identifies hardware manufacturers, device types, and potential service risks. / يتعرف تلقائياً على أنواع الأجهزة والشركات المصنعة.
* **Modern Interface (واجهة احترافية):** Features a clean, high-visibility terminal dashboard. / واجهة سطر أوامر متطورة واحترافية.

### ⚙️ Installation / طريقة التثبيت

#### **Windows**
1. Clone the repo: 
   `git clone https://github.com/MrAlmm/Almm_Scan.v10.0.git`
2. Install dependencies: 
   `pip install -r requirements.txt`
3. Run as **Administrator** (Command Prompt): 
   `python main.py`

#### **Kali Linux**
1. Clone the repo: 
   `git clone https://github.com/MrAlmm/Almm_Scan.v10.0.git`
2. Install dependencies: 
   `sudo pip3 install -r requirements.txt`
3. Run with **Root** privileges: 
   `sudo python3 main.py`

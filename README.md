ALMM-Scan v10.0 🚀
High-Speed, Stealth-Oriented Network Discovery & Asset Audit Suite.

[العربية]
ALMM-Scan v10.0 هو الجيل القادم من أدوات فحص الشبكات والتدقيق الأمني. تم تصميم هذه الأداة لتكون سلاحك السري في عمليات فحص الشبكات؛ فهي لا تكتفي بمسح البورتات فحسب، بل تقوم ببصمة الأجهزة (Fingerprinting) وتحديد الشركات المصنعة، كل ذلك عبر واجهة احترافية متطورة تجعل من مراقبة الشبكة عملية ممتعة وسريعة.

[English]
ALMM-Scan v10.0 is an advanced, multi-threaded network security auditing tool designed to surpass traditional scanners. Built with performance and anonymity in mind, it provides a comprehensive view of your network assets, hardware signatures, and open service vectors with lightning-fast execution.

🛡️ Key Features / المميزات الأساسية
Stealth Engine: Unlike standard scanners, ALMM-Scan employs a custom SYN Stealth approach to minimize exposure to IDS/IPS and Wireshark detection. / وضع التخفي: يستخدم تقنية SYN-Scan المخصصة ليعمل بعيداً عن أعين برامج المراقبة.

Blazing Performance: Leverages powerful Multi-threaded execution to audit hundreds of ports in seconds. / سرعة فائقة: يعتمد على المعالجة المتعددة لفحص مئات البورتات في ثوانٍ.

Intelligent Discovery: Automatically identifies hardware manufacturers, device types, and potential service risks. / كشف ذكي: يتعرف تلقائياً على أنواع الأجهزة والشركات المصنعة.

Modern Interface: Features a clean, high-visibility terminal dashboard. / واجهة احترافية: واجهة سطر أوامر متطورة واحترافية.

⚙️ Installation / طريقة التثبيت
Windows
Clone the repo: git clone https://github.com/MrAlmm/Almm_Scan.v10.0.git

Install dependencies: pip install -r requirements.txt

Run as Administrator: python main.py

Kali Linux
Clone the repo: git clone https://github.com/MrAlmm/Almm_Scan.v10.0.git

Install dependencies: sudo pip3 install -r requirements.txt

Run with Root: sudo python3 main.py
